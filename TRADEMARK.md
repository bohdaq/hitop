# Trademark policy

The code is open source; the name is not. "HITOP", "hitop" and the HITOP logo identify the
project and its official builds, and they stay with Bohdan Tsap.

You may:

- use the name to refer to the project, for example "works with HITOP" or "a fork of HITOP";
- ship unmodified official builds under the name.

Please don't, without written permission:

- publish a modified build, a fork or a hosted service under the HITOP name or logo;
- use the name or logo in a way that suggests the project endorses you.

A fork is welcome under its own name. Ask through an issue if you're unsure.
