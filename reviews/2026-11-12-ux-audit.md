# HITOP web app: hands-on UX assessment (2026-11-12, main 7034dc4)

Web build at localhost (plus a brief look at the Tauri harness and the live site). Real sends to httpbin, jsonplaceholder, countries.trevorblades.com (GraphQL), echo.websocket.org, stream.wikimedia.org (SSE), grpcb.in and a local no-CORS server. States: fresh first visit, and the `tests/visual.cjs` "shop-api" seed. Screenshot numbers refer to the audit's local screenshot set (not committed).

Owner decision 2026-11-12: all ten items plus the smaller findings go into UX2 (HITOP_NEXT_UI.md).

## Top 10, ranked by user impact

1. **WebSocket and gRPC addresses are invisible (S).** The URL `<input>` text is transparent (V1 draws visible text as a `.url-vars` mirror), but the mirror isn't rendered for WS/gRPC. Typing, connecting and saved WS requests all show an empty bar; live too. Change: render the mirror for every kind, or make text transparent only when a mirror exists (`data-mirror`); e2e in websocket.cjs/grpc.cjs that the computed colour isn't transparent.
2. **Pasting curl isn't understood (M).** Pasted into the URL bar the whole command becomes the URL (method stays GET, auto-name `GET //httpbin.org/post' -H …`); Import says "That isn't valid JSON"; only Ask AI (own Anthropic key) parses it. Change: pasted text starting `curl ` (optionally after `$`) is parsed deterministically (`-X`, `-H`, `-d`/`--data*`, `-u`, `--url`), fills the open request, toast "Imported from curl · Undo"; Import accepts curl as one request in the current collection; parser lives next to hitop-core's curl export.
3. **Rail pages replace the editor and hide the tabs (M).** History, Environments, Cookies, Settings take over the main area; the crumb says "Collections" on all; the rail's Collections icon opens the overview cards, not the request. Change: Collections icon always returns to the workspace (tabs/editor as left; overview stays in crumb menu "All collections"); Esc on a rail page returns; crumb names the page; optionally History in the side pane.
4. **Response body gets too little room (M).** At 1440×900 the body starts ~y=430 (label, status, two-row timing legend, duplicate "Reused connection", "Total", tabs, Pretty/Raw/Wrap/Find row). With checks, save/compare icons wrap. At 1024×768 Save and ⋯ wrap under the URL bar and the body is below the fold; the 320 px side pane can't be hidden. Change: one header line (status, time, size) + one-line waterfall with legend on hover/focus, no duplicates; body tools on the response tab row; Save/⋯ stay on the URL row (Save folds into ⋯ below 1100 px); side-pane toggle Mod+B, remembered in `hitop_layout`, collapsed by default ≤1200 px with a request open.
5. **First visit: "+" files requests into the sample (S).** List posts is open, so +, Alt+Shift+N and the palette add to "Sample: JSONPlaceholder" while My requests stays empty. Change: `store.contextCollection` uses the untouched sample only when explicitly targeted (its row's +, its folder, its page); otherwise My requests.
6. **Binary responses render as garbage; Diff vs last unstyled (M).** image/png shows mojibake in Pretty; Diff compares across different URLs, has no padding, raw "Differs: 3 headers, body."; Find keeps its old query across responses. Change: view by Content-Type (`image/*` → `<img>` + dimensions; PDF → sandboxed frame; other binary → "Binary · 14.5 KB · image/png" + Download + hex of first 4 KB); Diff only against earlier responses with same method+URL, else say none; pad the panel; compare binary by size+hash; clear Find on a new response.
7. **Failures and long waits don't read as failures (S).** Failed check keeps a green "200 OK"; Tests chip "1/2" not red; network errors are raw engine text ("couldn't reach the server: failed to lookup address information…", gRPC "transport error: received corrupt message of type InvalidContentType"); in flight only a skeleton, no elapsed time; Esc doesn't cancel. Change: failing checks → red Tests chip and "n of m" (`--hitop-fail`) + red rule on the response header; map common engine errors to headline + next step with raw text under Details (host not found, connection refused, TLS, gRPC "isn't speaking gRPC over TLS: try `http://`"); live "Waiting · 1.4 s" timer; Esc in the request pane cancels.
8. **SSE only works with a hand-typed Accept header (S).** Without `Accept: text/event-stream` a stream spins forever (skeleton at 26 s); cancel says "You stopped the request before its response arrived". No SSE in the method menu (gRPC needs scrolling). Change: switch to the Events view whenever response `content-type` is `text/event-stream`; add "Server-Sent Events" to the method menu (GET + Accept header, SSE tab tag); all 10 menu items fit without scrolling.
9. **Collection tree isn't a keyboard tree (M).** Row, +, ⋯ and reorder handle are separate Tab stops (~45 Tabs for 13 requests); arrows do nothing; context menu has no shortcuts/icons, Delete not set apart, 16 px rows. Change: one Tab stop with roving tabindex (`role=tree`/`treeitem`, `aria-expanded`): Up/Down move, Left/Right fold/parent, Enter opens, F2 renames, Delete asks, Shift+F10/menu key opens the menu; +, ⋯, handles `tabindex=-1`; keyboard reorder Alt+Up/Down.
10. **Signed-out Organization page has no Sign in button (S).** `views/org-view.js` (~401, ~407) uses `slot="action"`, but `lit-material-empty-state`'s slot is `actions`, so Sign in and "Try again" never render. Portal links like `#org=o-x&section=plan` do nothing signed out. Change: `slot="actions"` + a check flagging `slot="action"` inside an empty-state (alert correctly uses `action`); a signed-out `#org=` link calls `openSignIn(then)` ("Sign in to open Acme's Plan & billing") and continues to that section.

## Remaining findings, by area

**First visit**
- Two Import links at once; each collection gets a request-like "Variables" row.
- Get started (~180 px) + storage card (~90 px) leave the tree ~420 px at 900 px tall; collapse the card after step 1.
- Importing Postman ticks "Save a request to a collection".

**Request editor**
- Auto-named tabs ("GET /json") get no coloured method tag, unlike saved tabs.
- Tab overflow: active tab cut at the right edge, × hidden; tabs ~245 px. Cap width + "all tabs" list.
- GET Body tab "GET requests have no body" has no "Switch to POST".
- Method menu: 16 px plain rows instead of coloured mono tags; gRPC below the fold; method box width changes between GET and POST, shifting the URL.
- Focused editors' 2 px accent box overlaps the first line number.
- Empty scripts have no placeholder or one-click snippets.
- Body and header `${vars}` aren't highlighted or peekable (URL only).
- No header name autocomplete.
- Bearer token field not masked.
- GraphQL query/variables editors unlabelled, query editor 300 px wide, tab reads "GQL POST /graphql".
- Discard dialog has no Save; its 28 px title wraps.

**Response**
- JSON doesn't wrap by default; no folding or line numbers.
- SSE events are raw ~25-line JSON walls.
- Opening a History entry doesn't show its stored response.
- Copy button floats over the first body line.

**Collections and runs**
- Imported Postman "Folder A" shows as "folder-a" (file slug); keep a display name or title-case the slug.
- Collection page lists requests flat, ignoring folders; trash icon on every row.
- Failed run tile reads "0/1 · 1 failed", hides "12 not run".
- Tree intermittently loses chevrons/indentation (after a row menu, after returning from a rail page).
- Request context menu lacks Run, Copy as cURL, Open in new tab.
- Export has no collection picker and writes empty header rows.
- OpenAPI report offers "Cancel / Done" after the import happened; single "Done".

**History, environments, cookies**
- History lead "load it into the current tab" is stale since FV1.
- Environment menu has no "Manage environments…" once envs exist.
- Environments have no colour/production guard, no Duplicate.
- Cookie add row has two unlabelled fields.

**Palette and shortcuts**
- "import" ranks a fuzzy request above the exact Import action.
- Ctrl+P Quick open is a separate older dialog and labels auto-named requests "Untitled".
- Shortcut list says "(a draft asks where)" (stale); no keys listed for cancel, env switch, response tabs, sidebar filter.
- ">org" finds nothing signed out.

**Settings, sign-in, org**
- Settings says "the sparkle button next to Send", but Ask AI is in ⋯. One long page, no section index.
- Without a key the agent sheet only says "Open Settings" instead of taking the key inline; Esc closes it but focus goes to `<body>`.
- When `/v1/auth/methods` can't be reached the dialog silently drops to SSO with no retry.
- Org banner says "Sign in to hitop sync first" (`sync.js:295`); everywhere else "HITOP Cloud".

**Toasts, menus, consistency**
- Toasts appear top centre over the ⌘K field.
- ⋯ menu items are `role=listitem`, menu flush to the right edge, no icons/key hints.
- Focus ring is a white rectangle on sub-tabs and env pill, accent elsewhere.
- Dialogs use 28 px titles; Import textarea keeps the floating MD3 label; Code dialog 1100 px wide for one line.
- Response panel surface stops where its content ends.

**Narrow screens**
- At 390 px on touch, Send shows "Ctrl + Enter" and palette/status bar show key hints; hide under `pointer: coarse`.
- Status bar wraps to 89 px; after Send the response is ~960 px down with no jump to it.

**Not assessed:** signed-in sync, library, sharing, members, billing with real data, conflicts, Git page; AI with a key; real macOS app and browser extensions.

## What works well (keep)
- Palette: sections, prefixes, preview pane, key hints.
- Variable peek with source and Edit; undefined variables red and dashed.
- Timing waterfall and HTTP-version facts.
- Live JSON error with line/column; "Valid JSON · OpenAPI · createOrder".
- Run report: tiles, timeline, failure card, `hitop run … --bail` line with JUnit and report.json.
- OpenAPI import report.
- CORS and time-limit error texts (model for other errors).
- WebSocket log; GraphQL schema completion.
- Find in a 1 MB body (~0.3 s); sandboxed HTML Preview.
- Sign-in dialog and limit dialog.
- Collection and folder ⋯ menus.
- Desktop parity ("Local engine · Rust").
