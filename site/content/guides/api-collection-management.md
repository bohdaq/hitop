## About API Collection Management

Collections help you organize related API requests together, making it easy to manage, share, and run groups of tests. HITOP provides powerful collection features to keep your API tests organized and maintainable.

## Collection Features

-   Group related API requests together
-   Share collections with team members via export/import
-   Run entire collections sequentially
-   Collection-level variables and settings
-   Organize by feature, resource, or workflow
