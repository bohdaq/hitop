## About API collection management

Collections help you keep related API requests together, making it easy to manage, share, and run groups of tests. HITOP stores your collections on your device and gives you simple tools to keep your API tests organized and maintainable.

## Collection features

-   Group related API requests together
-   Share collections with team members by exporting and importing them
-   Run entire collections sequentially
-   Collection level variables and settings
-   Organize by feature, resource, or workflow
