## About Offline API Testing

HITOP works completely offline once loaded, making it perfect for testing APIs in secure environments, on airplanes, or anywhere without reliable internet connectivity. All your collections and data are stored locally.

## Offline Capabilities

-   Full functionality without internet connection
-   Test local development APIs (localhost)
-   Perfect for secure/isolated environments
-   No dependency on external services
-   All data stored in browser local storage
-   Work on planes, trains, or remote locations
