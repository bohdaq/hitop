## About privacy focused API testing

Privacy is critical when testing APIs, especially for internal services or sensitive data. HITOP stores all data on your device: your API endpoints, authentication tokens and test data are never synced to a cloud. The web app sends requests to public APIs through the HITOP request proxy, which keeps nothing; the Mac and iOS apps, the CLI and the extensions send them straight from your device.

## Privacy features

-   Collections and history stored on your device; cloud sync only if you sign in to HITOP Cloud (shared collections end to end encrypted)
-   No account required, so no personal data collected
-   Good for testing internal or private APIs with the Mac app, CLI or an extension
-   Mac app, iOS app and CLI work offline for complete isolation
-   Web app, extensions and CLI are open source under the MIT License, so you can audit them
