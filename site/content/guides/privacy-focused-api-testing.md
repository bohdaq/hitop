## About Privacy-Focused API Testing

Privacy is critical when testing APIs, especially for internal services or sensitive data. HITOP stores all data locally on your device: your API endpoints, authentication tokens and test data are never synced to a cloud. The web app sends requests to public APIs through the HITOP request proxy, which keeps nothing; the Mac and iOS apps, the CLI and the extensions send them straight from your device.

## Privacy Features

-   100% local data storage - no cloud sync
-   No account required - no personal data collected
-   No cloud sync: collections and history stay on your device
-   Perfect for testing internal/private APIs
-   Works offline for complete isolation
-   Open source - transparent and auditable
