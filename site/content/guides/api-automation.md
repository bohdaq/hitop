## About API automation

API automation lets you run many API tests automatically, saving time and improving test coverage. HITOP gives you scripts that run before the request and after the response, a collection runner, and variable interpolation to streamline your API testing workflows.

## Key automation features

-   Script before: generate dynamic data before the request is sent
-   Script after: validate the response once it arrives
-   Collection runner for sequential test execution
-   Collection variables for flexible testing
-   JavaScript scripting engine
