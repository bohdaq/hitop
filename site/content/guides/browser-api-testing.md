## About browser API testing

Testing APIs in the browser removes the need for a desktop application. The HITOP web app at hitop.rws8.tech/app/ runs in your browser, giving you a fast, lightweight way to test APIs from any device. Requests to public APIs go through the HITOP proxy, so you get no CORS errors. Requests to localhost go straight from your browser, so a local API must allow the origin https://hitop.rws8.tech in its CORS settings.

## Benefits of testing in the browser

-   No installation required: start testing immediately
-   Works on any operating system with a browser
-   Always up to date, with no manual updates
-   Lightweight and fast
-   Free, no account needed
-   Collections and history stored on your device

For machines on your local network, use the Mac app, the CLI, or the Chrome or Firefox extension.
