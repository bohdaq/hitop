Privacy Policy

HITOP — HTTP API Testing Tool  ·  Last updated: June 2025

Summary

HITOP does not collect, store, or transmit any personal data. No account is required.

Data Storage

All data you enter — collections, requests, headers, variables, and request history — is stored locally on your device:

  • macOS: ~/Library/Application Support/hitop/
  • Linux: ~/.config/hitop/
  • Windows: %APPDATA%\hitop\

This data never leaves your device unless you explicitly export it yourself.

Network Requests

The only network requests HITOP makes are the HTTP requests you explicitly configure and send using the tool. HITOP does not make any background network requests, analytics calls, or telemetry pings.

No Tracking

HITOP contains no:

  • Analytics or usage tracking
  • Crash reporting
  • Advertising identifiers
  • Third-party SDKs that collect data

Children's Privacy

HITOP does not knowingly collect any information from anyone, including children under the age of 13.

Changes

If this policy changes, the updated version will be posted at this URL with a new "Last updated" date.
